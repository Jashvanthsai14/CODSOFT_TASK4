# CODSOFT Task - Spam SMS Detection

## Project Description
This project detects whether an SMS message is Spam or Legitimate using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes
- Matplotlib

## Machine Learning Process
1. Data loading
2. Data preprocessing
3. TF-IDF text vectorization
4. Train-test split
5. Naive Bayes model training
6. Model evaluation
7. SMS prediction

## Model
Multinomial Naive Bayes

## Output
The model classifies SMS messages as:
- Spam
- Legitimate
